Ko‘rinish

Bulutni sichqoncha yoki barmoq bilan torting — aylanadi; g‘ildirak yoki ikki barmoq bilan yaqinlashtiring, o‘ng tugma bilan suring. Kamera moslashuvini o‘chirsangiz, barcha bulutlar bir xil masshtabda ko‘rinadi.

Nima bo‘lyapti?

Formulalar

  • To‘lqin funksiyasi: ψₙₗₘ(r, θ, φ) = Rₙₗ(r)·Yₗᵐ(θ, φ)
  • Ehtimollik: dP = |ψ|² dV, radial taqsimot P(r) = r²Rₙₗ²
  • Energiya: Eₙ = −13,6 eV / n²
  • Kvant sonlari: n = 1, 2, …; l = 0 … n − 1; mₗ = −l … +l
  • Impuls momenti: L = ħ√(l(l + 1)), Lz = mₗħ
  • O‘rtacha radius: ⟨r⟩ = a₀(3n² − l(l + 1))/2, a₀ = 0,529 Å
  • Tugunlar: radial n − l − 1, burchak l, jami n − 1

Har bir nuqta — elektronni bir marta «o‘lchaganda» topish mumkin bo‘lgan joy: nuqtalar |ψ|² taqsimotidan tasodifiy tanlanadi, shuning uchun zich joyda elektron ko‘proq uchraydi. Rang — to‘lqin funksiyasining ishorasi (kompleks holatlarda faqat Rₙₗ·Θₗₘ qismining ishorasi, eimφ fazasi ko‘rsatilmaydi). Yadro (proton) masshtabi saqlanmagan: aslida u atomdan ~10⁵ marta kichik.
