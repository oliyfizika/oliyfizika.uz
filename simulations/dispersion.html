Formulalar

  • Dispersiya: n = n(λ), Koshi formulasi n ≈ A + B/λ² — binafsha nur kuchliroq sinadi
  • Prizmada og‘ish: δ = α₁ + α₂ − A, rangga qarab turlicha
  • Kamalak: tomchida og‘ish D = k·180° + 2i − 2(k+1)r; birlamchi ≈ 42°, ikkilamchi ≈ 51°
  • Malyus qonuni: I = I₀·cos²θ; qutblanmagan nur polyaroiddan keyin I₀/2
  • Bryuster qonuni: tg αB = n — qaytgan nur to‘liq qutblangan

Shishalarning n(λ) qiymatlari haqiqiy kataloglardagi F va C chiziqlari bo‘yicha Koshi formulasiga moslangan. Prizmadagi nurlar 2D nur kuzatuvchi bilan aniq hisoblanadi; burchaklar yaqqol bo‘lishi uchun spektr yoyilishi chizmada kattalashtirilmagan.
