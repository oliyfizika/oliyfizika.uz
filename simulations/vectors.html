Simulyatsiyalarga qaytish
Mexanika

Vektorlar va kuchlarni qo‘shish

Parametrlar

Tayyor tajribalar
Vektor a

Vektor uchidagi doirachani sahnada suring — modul, yo‘nalish va proyeksiyalar o‘zgaradi.

Qo‘shish

a (ko‘k) va b (yashil) vektorlar uchlarini sahnada suring.

Kuchlar

Kuchlar uchidagi doirachalarni sahnada suring. 1 katak = 1 N.

Panjara

Nima bo‘lyapti?

Formulalar

  • Proyeksiyalar: ax = a·cosα, ay = a·sinα
  • Modul: a = √(ax² + ay²), yo‘nalish: tgα = ay/ax
  • Qo‘shish: (a + b)x = ax + bx, (a + b)y = ay + by
  • Kosinuslar teoremasi: |a + b| = √(a² + b² + 2ab·cosθ)
  • Teng ta’sir etuvchi kuch: R = F₁ + F₂ + … + Fn; muvozanat: R = 0

Vektorlar tekislikda (ikki o‘lchovli). Burchak α — x o‘qidan soat strelkasiga teskari hisoblanadi. Kuchlar bitta nuqtaga (jismga) qo‘yilgan deb olinadi.
