Formulalar

  • Tomson formulasi: T = 2π√(LC), ω₀ = 1/√(LC)
  • Energiya: q²/(2C) + Li²/2 = const (R = 0)
  • So‘nish: β = R/(2L), aperiodik rejim R ≥ 2√(L/C)
  • Reaktiv qarshiliklar: XL = ωL, XC = 1/(ωC)
  • Om qonuni: I = U/Z, Z = √(R² + (XL − XC)²), tg φ = (XL − XC)/R
  • Quvvat: P = UefIefcos φ; rezonans: f₀ = 1/(2π√(LC)), Q = √(L/C)/R

LC konturda tebranish tenglamasi RK4 usulida yechiladi (analitik yechimga mos). O‘zgaruvchan tok rejimlarida barqaror holat ko‘rsatiladi; animatsiya sekinlashtirilgan, sonlar esa haqiqiy chastota bo‘yicha.
