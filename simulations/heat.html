Formulalar

  • Isitish / sovitish: Q = c m (t₂ − t₁)
  • Erish (qotish): Q = λ m
  • Bug‘lanish (kondensatsiya): Q = L m
  • Yoqilg‘ining yonishi: Q = q m
  • Issiqlik balansi: Qberilgan = Qolingan, ya’ni Σ Q = 0
  • Aralashma temperaturasi: θ = (c₁m₁t₁ + c₂m₂t₂) / (c₁m₁ + c₂m₂)
  • Qizdirgich FIK: η = Qfoydali / Qyonish

Normal atmosfera bosimi. Qiymatlar maktab darsliklari jadvallaridan: csuv = 4200, cmuz = 2100 J/(kg·°C), λmuz = 3,4·10⁵ J/kg, Lsuv = 2,3·10⁶ J/kg. Hisob: entalpiya bo‘yicha issiqlik balansi (Node’da tekshirilgan).
